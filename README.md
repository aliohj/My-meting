# Quartz | كوارتز — Logo Overlay

فيديو المنتجات مع شعار كوارتز في الزاوية السفلية اليمنى.

- **نسخة 1080p:** `output/quartz-video-logo-1080p.mp4` (1920×1080، الشعار مرسوم بدقة 1080p عشان يطلع حاد)
- **نسخة بدقة المصدر:** `output/quartz-video-logo.mp4` (854×480)
- النسختين: 24 إطار/ث، 15 ث، والصوت الأصلي بدون تعديل
- **مكان الشعار:** الزاوية السفلية اليمنى بهامش آمن. عرض الشعار 260px، أي تقريباً 30% من عرض الفيديو
- **ظل ناعم:** ظل بطبقتين خلف الشعار عشان يبان على القماش الأبيض وعلى الخلفيات الداكنة
- **ظهور واختفاء:** يظهر تدريجياً من 0.4 ث إلى 1.2 ث، ويختفي تدريجياً من 12.7 ث إلى 13.3 ث قبل ما يطلع الشعار الأصلي في نص الفيديو (عند 13.5 ث تقريباً)، فما يتكرر الشعار مرتين

## إعادة الإنتاج

```bash
./scripts/render.sh        # 854×480
./scripts/render.sh 1080   # 1920×1080
```
