# موقع الفطيم العربي — التصميم الجديد

موقع ثابت (HTML/CSS/JS بدون أي مكتبات) بالعربي والإنجليزي، 8 صفحات بنفس المحتوى والبيانات الأصلية.

## الفكرة

الموقع مصمم كأنه **مجموعة مخططات مقاول**: خلفية بيضاء مثل لوح البوليسترين، رمادي طبقة الأساس، كحلي غامق للنص، أزرق الشعار للعزل، وبرتقالي السقالات (لون الكابلوك المصبوغ) لقسم السقالات.

- **الخطوط (مستضافة داخل الموقع):** Archivo Expanded للعناوين الإنجليزية، Reem Kufi للعناوين العربية، IBM Plex Sans Arabic للنص العربي، IBM Plex Mono للأرقام والبيانات.
- **العنصر الأساسي في الرئيسية:** مخطط متحرك لمقطع الجدار. تُركَّب السقالة طابق بعد طابق، ثم تُطبَّق طبقات العزل الثماني في التفصيل A، وينزل معامل الانتقال من 2.38 إلى 0.54 واط/م²·كلفن (تحت حد الهيئة 0.57)، وبعدها تُفك السقالة من الأعلى وتبقى مرسومة بخط متقطع مثل الأعمال المؤقتة في المخططات. الأرقام محسوبة من شهادة الهيئة (λ = 0.0382، لوح 55 مم، جدار بلوك 200 مم).

## الحركة والانتقالات

- انتقال سلس بين الصفحات (View Transitions) في Chrome وEdge وSafari الحديث، والهيدر يبقى ثابتًا أثناء الانتقال.
- العناوين تظهر كلمة كلمة، والصور تنكشف بستارة بلون القسم، والأرقام تعدّ عند ظهورها.
- خط الهيدر يُرسم عند فتح كل صفحة، والهيدر يختفي عند النزول ويرجع عند الصعود.
- فلترة المشاريع بانتقال ناعم، ومعاينة صورة المشروع تلحق المؤشر على الكمبيوتر.
- شهادات الهيئة تنفرد مثل أوراق على مكتب، وشريط صلاحية كل شهادة محسوب من تاريخ اليوم.
- خطوات العمل (العزل والسقالات) تنرسم بالتسلسل عند الوصول لها.
- كل الحركة تتوقف تلقائيًا لمن مفعّل «تقليل الحركة» في جهازه.

## البنية

```
alfitaim/
  index.html about.html services.html projects.html
  approvals.html news.html inquiries.html contact.html
  assets/css/site.css        كل التصميم (ألوان، خطوط، مكوّنات، حركة، وضع داكن، RTL)
  assets/js/site.js          اللغة، القائمة، الظهور عند التمرير، العدّادات، عارض الصور، النسخ
  assets/js/data.js          بيانات المشاريع العشرين وطبقات العزل الثماني
  assets/js/home.js          مخطط الجدار المتحرك + أحدث المشاريع
  assets/js/services.js      مستكشف الطبقات + فحص معامل الانتقال
  assets/js/projects.js      تبويبات القطاعات والفلترة وسجل المشاريع
  assets/js/inquiries.js     نموذج الطلب وحاسبة السقالات ورسالة واتساب
  assets/fonts/              الخطوط (رخصة OFL)
  img/                       الصور الأصلية + أيقونة الموقع
```

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادم محلي:

```bash
cd alfitaim && python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

للنشر: ارفع مجلد `alfitaim/` كما هو على أي استضافة ثابتة (GitHub Pages أو Netlify أو استضافة الشركة).

## تعديل المحتوى

- النصوص موجودة داخل صفحات HTML بالشكل `<span data-l="en">…</span><span data-l="ar">…</span>`، عدّل الاثنين معًا.
- المشاريع والأرقام في `assets/js/data.js` (الإجماليات والعدّادات تنحسب تلقائيًا منها).
